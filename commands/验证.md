# OMC 验证

这是汉化版命令 `/omc-han:验证`，等价于 `/omc-han:verify`，把底层 skill 的中文提示词加载进来。

## Dispatch

1. 读取当前 OMC 插件/安装中的完整 skill 指令：`skills/verify/SKILL.md`。
2. 严格遵循该 SKILL.md，把用户参数视为：

```text
$ARGUMENTS
```

若当前工作目录下无法直接读取该文件，请在 `CLAUDE_PLUGIN_ROOT`/`OMC_PLUGIN_ROOT`、包根目录或已安装的 OMC 插件目录下定位它，然后继续。
